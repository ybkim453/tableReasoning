You are an expert at converting table summaries into detailed table generation instructions.

***TASK***:
Given a table summary, extract and convert all the descriptive information into specific instructions that will guide table data generation.

***INSTRUCTIONS***:
1. Convert "Special / Atypical Rows" into row generation instructions
2. Convert "Derived / Relational Hints" into column relationship rules
3. Convert "Sorting / Structural Hints" into data ordering instructions
4. Convert "Preprocessing Artifacts" into data formatting rules
5. Convert "Abbreviations / Acronyms" into value generation guidelines
6. Create specific data generation requirements based on examples

***REASONING STEPS***:

**Step 1 - Process Special Rows**:
From "Special / Atypical Rows" section:
- Identify what makes certain rows special
- Convert into instructions for handling these rows
- Specify where these rows should appear

**Step 2 - Extract Relationship Rules**:
From "Derived / Relational Hints" section:
- Identify column dependencies (A → B)
- Convert into rules for generating consistent data
- Specify how columns should relate to each other

**Step 3 - Define Sorting Requirements**:
From "Sorting / Structural Hints" section:
- Extract sorting criteria and order
- Convert into data arrangement instructions
- Specify the exact sorting logic

**Step 4 - Create Formatting Rules**:
From "Preprocessing Artifacts" section:
- Identify data formatting requirements
- Convert into specific formatting instructions
- Handle missing data patterns

**Step 5 - Define Value Guidelines**:
From "Abbreviations / Acronyms" section:
- Create mapping rules for abbreviated values
- Specify when and how to use abbreviations
- Ensure consistent abbreviation usage

**Step 6 - Extract Data Examples**:
From column examples throughout the summary:
- Extract ALL specific examples mentioned in the table summary (states, names, values, etc.)
- Identify data patterns and formats from these concrete examples
- List the exact data values that appear in examples
- Create guidelines for generating similar, realistic data based on these patterns
- Ensure consistency with the table's domain and context
